1. Who We Are

TikTok Content System ("Application," "we," "us," or "our") is a developer-operated tool that integrates with the TikTok Content Posting API to enable automated video publishing. The Application is operated by an individual developer reachable at themasionchef@gmail.coma>.

2. Information We Collect

We collect the minimum data necessary to provide the service:

Data Type What It Is Why We Collect It
TikTok OAuth Tokens Access token and refresh token issued by TikTok after you authorize the Application Required to post content and retrieve analytics on your behalf without you re-authenticating each time
TikTok Profile Data Display name, username, and open_id (TikTok's unique user identifier) Identifies which account to publish to; displayed in the dashboard
Follower & Engagement Metrics Follower count, view counts, like counts, comment counts for posted videos Powers the analytics dashboard and performance scoring features
Video Content Video files and metadata (caption, hashtags, schedule time) you configure for publishing Required to upload and publish content to TikTok on your behalf
Usage Logs Server-side logs of API calls, errors, and job queue events Debugging, system reliability, and audit trail for published actions
div>

We do notstrong> collect passwords, payment information, government IDs, precise geolocation, or any data beyond what is listed above.

3. API Scopes

The Application requests only the following TikTok API scopes, each limited to its stated purpose:

  • user.info.basic — Retrieves your TikTok display name, username, and open_id so the Application can identify which account to publish to and display account information in your dashboard.
  • video.upload — Allows the Application to upload video files to TikTok's servers on your behalf as part of the content publishing pipeline.
  • video.publishstrong> — Allows the Application to finalize and publish uploaded video content to your TikTok profile according to your configured schedule and settings.

No additional scopes are requested. If scope requirements change in a future version, this policy will be updated and you will be asked to re-authorize.

4. How We Use Your Information

  • Content publishing: Using your OAuth token to call the TikTok Content Posting API and publish scheduled videos to your account.
  • Analytics:strong> Fetching post performance metrics from TikTok's API and displaying them in your dashboard.
  • Authentication: Refreshing your OAuth token before it expires so the Application can continue operating without interruption.
  • System operations: Logging errors and pipeline events for debugging and reliability monitoring.

We do notstrong> use your data for advertising, profiling, or any purpose unrelated to operating the Application.

5. TikTok API Data Use

The Application accesses TikTok user data exclusively through TikTok's official API and only with your explicit OAuth consent. Our use of data obtained from TikTok's API complies with TikTok's API Terms of Servicea> and Developer Termsa>.

  • Data obtained through TikTok's API is used only to provide the features you explicitly requested.
  • We do not transfer TikTok user data to third parties for advertising or data broker purposes.
  • We do not use TikTok data to build profiles unrelated to operating the Application.

6. Data Storage & Security

OAuth tokens and profile data are stored in a PostgreSQL database hosted on AWS RDS. The database resides in a private VPC subnet with no public internet access. Tokens are encrypted at rest using AES-256 and in transit via TLS 1.2+. Access to the database is restricted to Application services running in the same private subnet.

Video files are stored temporarily for upload processing and are deleted from our servers within 24 hours of a successful or failed upload attempt.

7. Data Retention

  • OAuth tokens: Retained for as long as your account is active. Deleted immediately upon revocation or account deletion.
  • Profile & metrics data: Retained for the duration of your active connection. Deleted within 30 days of disconnecting your TikTok account.
  • Video content:strong> Deleted within 24 hours of processing.
  • System logs: Retained for up to 90 days for debugging purposes, then automatically purged.

8. Sharing of Information

We do not sell, rent, or trade your personal information. We share data only in these limited circumstances:

  • TikTok: We transmit video content and metadata to TikTok via their API to fulfill your publishing requests. This is the core function of the Application.
  • AWS: Infrastructure services (RDS, ElastiCache, ECS, Secrets Manager) that host and operate the Application. AWS processes data as a data processor under our direction.
  • Legal requirements: If required by law, court order, or to protect the safety of individuals, we may disclose information to appropriate authorities.
